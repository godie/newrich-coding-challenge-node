# Coding Challenge Starter (NestJS + React)

Minimal starter repository for the fullstack coding challenge.

All candidate instructions are in [`CHALLENGE.md`](./CHALLENGE.md).

## Run backend

```bash
cd api
npm install
npm run start:dev
```

API default URL: `http://localhost:3001`

## Run backend tests

```bash
cd api
npm test
```

## Frontend workspace

Create the React app inside `web/`.
