# Web - React Frontend
React frontend with drag-and-drop reordering, filtering, and sorting capabilities.
## Requirements
- Node.js 18+
- npm 9+
## Installation
```bash
npm install
```
## Running
```bash
npm run dev
```
Frontend runs on **http://localhost:5173**
## Testing
```bash
npm test
```
## Features
- Drag-and-drop reordering with @dnd-kit
- Filter by active status
- Filter by category
- Text search (debounced)
- Column sorting
- Responsive design
